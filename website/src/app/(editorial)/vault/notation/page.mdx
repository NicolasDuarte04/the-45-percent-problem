This table mirrors the notation in the Phase 1 framework paper. Every symbol
listed here appears in the model specification, the evaluation metrics, or
the pre-registration constants. The canonical value column shows the
pre-registered value where the symbol has one; "n/a" denotes a variable or a
value estimated from data.

Symbols are grouped thematically: model parameters first, then market and
evaluation quantities, then meta and infrastructure notation.

| <InlineMath math="\lambda_3" /> | Bivariate Poisson shared-shock parameter | 0.10 | Pre-registered; common-shock term in Karlis-Ntzoufras decomposition |
| <InlineMath math="c^{*}" /> | Elo-to-log-rate slope | 0.580386 | Pre-registered; calibrated on 2010 to 2021 corpus |

The log-linear parameterization of expected goals:

<BlockMath math="\log \lambda_h = \mu + \alpha_h - \beta_a + \delta_\text{HFA}" />
<BlockMath math="\log \lambda_a = \mu + \alpha_a - \beta_h" />

The simulation engine's calibrated Elo-to-rate mapping (used at run time):

<BlockMath math="\lambda_h = \mu^{*} \cdot e^{\,c^{*} (R_h + H - R_a)/400}" />
<BlockMath math="\lambda_a = \mu^{*} \cdot e^{-c^{*} (R_h + H - R_a)/400}" />

<BlockMath math="\tau(x,y,\lambda_h,\lambda_a,\rho) = \begin{cases} 1 - \lambda_h\lambda_a\rho & x=0,\; y=0 \\ 1 + \lambda_h\rho & x=0,\; y=1 \\ 1 + \lambda_a\rho & x=1,\; y=0 \\ 1 - \rho & x=1,\; y=1 \\ 1 & \text{otherwise} \end{cases}" />

## Market and edge quantities

| Symbol | Definition | Canonical value | Notes |
|--------|-----------|-----------------|-------|
| <InlineMath math="p_m" /> | Model-implied probability for outcome | n/a | <InlineMath math="p_m \in [0,1]" /> |
| <InlineMath math="q_\text{raw}" /> | Raw bookmaker decimal odds (inverted) | n/a | Before margin removal |
| <InlineMath math="q_d" /> | De-vigged market probability | n/a | Power-method de-vigging; <InlineMath math="\sum_j q_{d,j} = 1" /> |
| <InlineMath math="E" /> | Edge | n/a | <InlineMath math="E = p_m - q_d" />; positive = model higher than market |
| <InlineMath math="\varepsilon" /> | Edge threshold | 0.03 (mainline) / 0.05 (derivative) | Pre-registered; governs gate status |
| <InlineMath math="k" /> | Power-method exponent for de-vigging | n/a | Estimated to zero overround |
| <InlineMath math="z" /> | Power-method exponent (unnormalized form) | n/a | <InlineMath math="\sum_i r_i^{z} = 1" />; <InlineMath math="z > 1" /> for overround Pinnacle, <InlineMath math="z < 1" /> for underround exchanges |
| <InlineMath math="\Delta_{\text{draw}}" /> | Pinnacle knockout-draw bias correction | +0.014 | Pre-registered; additive on draw leg in knockout markets |
| <InlineMath math="\Delta_{\text{host}}" /> | Pinnacle group-stage host-win bias correction | −0.006 | Pre-registered; additive on host-win leg in group-stage markets |
| <InlineMath math="\sigma_p" /> | Monte Carlo standard error on <InlineMath math="p_{\text{model}}" /> | n/a | <InlineMath math="\sqrt{p(1-p)/N_{\text{MC}}}" /> |
| <InlineMath math="\sigma_q" /> | De-vigging uncertainty (parametric bootstrap) | n/a | 50 resamples, tick noise <InlineMath math="\pm 0.005" /> on decimal odds |
| <InlineMath math="E^{*}" /> | Variance-adjusted standardized edge | n/a | <InlineMath math="E / \sqrt{\sigma_p^{2} + \sigma_q^{2}}" />; logged but not flag-decisive |

The power-method de-vigging formula:

<BlockMath math="q_{d,i} = \frac{o_i^{-1/k}}{\displaystyle\sum_j o_j^{-1/k}}" />

where <InlineMath math="o_i" /> is the decimal odds for outcome <InlineMath math="i" />. The implementation uses the unnormalized form <InlineMath math="q_i = r_i^{z}" /> with <InlineMath math="z" /> chosen so that <InlineMath math="\sum_i r_i^{z} = 1" />, which produces an identical <InlineMath math="q" /> vector under a different parameterization of the exponent.
