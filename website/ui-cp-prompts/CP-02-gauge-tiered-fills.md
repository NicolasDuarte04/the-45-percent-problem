## 2. Task

Implement **CP-02. Tiered gauge fills + rolling percentage + inline tension label.** Verbatim from the architecture document, this means three behaviour changes inside `LiveAgreementGauge.tsx`:

1. **Tiered band fills.** The five segments of the gauge no longer all fill in `--accent-warm`. Each segment binds to its index-matched band token from CP-00:
   - index 0 (REALISTIC, pct ≥ 25%) → `--band-common`
   - index 1 (REALISTIC, pct ≥ 5%) → `--band-plausible`
   - index 2 (BOLD CALL, pct ≥ 1%) → `--band-uncommon`
   - index 3 (LONG SHOT, pct ≥ 0.1%) → `--band-rare`
   - index 4 (LONG SHOT, pct < 0.1%) → `--band-vanishing`
   Only the **active** segment fills; the other four stay in the existing outline state. The active-segment border continues to use `--accent-warm` as today (Phase E §8 D.3 behaviour), so the segmented bar still reads as "you are here" via the warm-tinted border around whichever band you landed on.
2. **Rolling percentage.** The percentage text to the right of the viral hook (currently swaps instantly when `count`/`total` changes) animates as a 220ms `tabular-nums` count-up from the previous displayed value to the new value. Use ease-out cubic (`[0.22, 1, 0.36, 1]`, matching the `tickRoll` preset registered in CP-00).
3. **Inline tension label.** Below the gauge frame, render a single mono line when `getLiveHook(count, total) === "LONG SHOT"` AND `isComplete` is true. Copy template: `long shot. only {count} in {total} sims agree.` Lowercase, no exclamation. Dismisses on band-change (e.g. user edits a pick and lands in BOLD CALL), on `isComplete` going false, and after 6 seconds of no `count`/`total` activity while still in LONG SHOT.

No other behaviour changes. The 3-state vocabulary (`REALISTIC` / `BOLD CALL` / `LONG SHOT`) and the band thresholds in `activeSegmentIndex` stay byte-for-byte unchanged.

### 2.1. File-by-file guidance

  const BAND_TOKEN_BY_INDEX = [

    "var(--band-plausible)",
    "var(--band-uncommon)",

For the rolling percentage:

- Create a new hook at `src/lib/motion/useRollingNumber.ts`. Signature:
  ```ts
  /**
   * Animate a numeric value with a 220ms tabular-nums roll. Honours
   * prefers-reduced-motion by snapping instantly. Reusable by CP-08
   * for the post-submit "1 in N" count-up.
   */
  export function useRollingNumber(
    target: number,
    options?: { durationMs?: number },
  ): number;
  ```
  Implementation: track the previous displayed value in a ref, run a `requestAnimationFrame` loop interpolating from `prev` to `target` with ease-out cubic. Cancel the rAF on unmount or when `target` changes mid-flight. Default duration 220ms. When `prefers-reduced-motion: reduce` matches, return `target` directly without animating. Use the existing `useReducedMotionAware` hook from `src/lib/motion/useReducedMotionAware.ts` to read the preference (or `useReducedMotion` from framer-motion if the project uses both; check existing usage and follow the local convention).
- In `LiveAgreementGauge.tsx`, compute `const targetPct = total > 0 ? (count / total) * 100 : 0;` and `const displayedPct = useRollingNumber(targetPct);`. Pass `displayedPct` through the existing `formatLivePercent` helper (or inline-format) to render the rolling value. The `isComplete` gate that today nulls the percent string stays as today.
- The roll is purely visual; do not change the canonicalisation pipeline (`computeRealityScore`, `canonicalizeScenario`). The hook only animates the *displayed* value; the underlying `count` / `total` props remain the truth.

For the tension line:

- Add a new `<TensionLine count={count} total={total} isComplete={isComplete} />` subcomponent inside `LiveAgreementGauge.tsx`. Place it as a sibling below the gauge `<section>`, inside the same component return, wrapped in `<AnimatePresence>` so its entry/exit animates with the existing `useReducedMotionAware("micro")` preset.
- The line renders only when `isComplete && getLiveHook(count, total) === "LONG SHOT"`. It dismisses (returns null) on the next render after any of the three conditions:
  1. `isComplete` flips to false.
  2. `getLiveHook` returns a non-LONG-SHOT value (band change).
  3. 6 seconds elapse with no `count` or `total` change since the last activity.
- Track the 6-second timer via `useEffect` keyed on `[count, total, isComplete]`. Resetting any of those resets the timer. When the timer fires, set a local `isExpired` state to `true`, which the render gate also reads.
- Copy: `long shot. only {count} in {total} sims agree.` Use `Intl.NumberFormat("en-US")` on `total` (so `10000` renders as `10,000`). Mono uppercase is wrong here; the line is intentionally lowercase to read as terminal-style commentary. Style: `font-mono text-[12px] text-[var(--ui-warning)]` (use the existing `--ui-warning` token if defined; else `--text-tertiary`). The line sits 8px below the gauge frame, max-width 320px to match the gauge.
